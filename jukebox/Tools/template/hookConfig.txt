<NAME>MoveToTop
<DESC>
MoveToTop is automatically invoked when a window is started from the menu (as read from the database or xml file) 
or as a tab-page (via JBoxMsTab), or when using methods like
- StartChildWindow, StartChildTab or StartTabWindow in JBoxMainMenu:Instance
- StartChildWindow in JBoxContainer

It's a good place to add code if you need to do more initialization based on the parent object that is automatically
assigned to the browse or query object defined in InitializeObject when using the window as a tab-page.

THIS-PROCEDURE:CURRENT-WINDOW:WINDOW-STATE = 3.
